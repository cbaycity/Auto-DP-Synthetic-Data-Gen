Dataset Source - Kaggle: https://www.kaggle.com/datasets/claudiodavi/superhero-set

Why use this dataset:
The `heroes_information.csv` file in the Super Heroes Kaggle Dataset has 733 heroes. It is a small dataset and has three integer or float columns which need to be classified as categorical or numeric. Ideally there is somewhat reasonable performance on this dataset.

# Columns to evaluate:
| Column | Classification |
| ------ | -------------- |
| index | categorical |
| Height | numeric |
| Weight | numeric |

### Modifications:
The index was included with this dataset but no column name was provided for it; but in this repo the index has been named "index".
