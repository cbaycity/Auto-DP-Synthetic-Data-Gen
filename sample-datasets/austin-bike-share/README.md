Dataset Source - Kaggle: https://www.kaggle.com/datasets/jboysen/austin-bike/data?select=austin_bikeshare_trips.csv

Why use this dataset:
The `austin_bikeshare_trips.csv` file in the Austin Bike Share Trips Kaggle dataset has roughly 649k records on bike trips completed. There are not that many columns however, so there is some possibility to contain the domain. It is worth figuring out how to perform well on a dataset like this.
