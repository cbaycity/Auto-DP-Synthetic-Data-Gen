Dataset Source - Kaggle: https://www.kaggle.com/datasets/jboysen/sf-street-trees/data

Why use this dataset:
The `san_francisco_street_trees.csv` file in the SF Street Trees Kaggle competition has over 100k samples on trees. It is a large dataset with 7 integer or float types that need to be classified as categorical or numeric. The latitude and longitude columns in particular are interesting to classify.

# Columns to evaluate
| Column | Classification |
| ------ | -------------- |
| site_order | categorical |
| tree_id | categorical |
| dbh | numeric |
| latitude | numeric |
| longitude | numeric |
| x_coordinate | numeric |
| y_coordinate | numeric |
