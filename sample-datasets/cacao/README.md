Dataset Source - Kaggle: https://www.kaggle.com/datasets/rtatman/chocolate-bar-ratings?resource=download

Why use this dataset:
The `flavors_of_cacao.csv` file in the Chocolate Bar Ratings Kaggle challenge has roughly 1.7k records on chocolate bars. This is a small dataset with three numeric columns that need to be classified as such. It should be harder than larger datasets to correctly evaluate.

# Columns to evaluate:
| Column | Classification |
| ------ | -------------- |
| REF | numeric |
| Cocoa Percent | numeric |
| Rating | numeric |
