Dataset Source - Kaggle: https://www.kaggle.com/datasets/aaronschlegel/seattle-pet-licenses

Why use this dataset:
This dataset has two columns of numeric dtype that need to be classified, a zip_code and license_number. Classifying zip codes is a standard problem so this hopefully is classified correctly.

# Columns to evaluate:
| Column | Classification |
| ------ | -------------- |
| zip_code | categorical |
| license_number | numeric |
