Dataset Source - Kaggle: https://www.kaggle.com/datasets/broach/california-kindergarten-immunization-rates/data?select=StudentData.csv

Why use this dataset:
The `StudentData.csv` file in the California Kindergarten Immunization Rates Kaggle challenge contains a raw per school in California with a nice mix of categorical and continuous columns. This is a medium size dataset which we expect algorithms to perform reasonably well on.
